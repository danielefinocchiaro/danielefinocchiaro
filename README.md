### 👨‍💻 About me

🇬🇧 I'm a **Full-Stack Developer** at **[Keix](https://keix.com)**, where we build an AI-native *Action Intelligence* platform that turns data into decisions. I love shipping fast, type-safe web apps — from the database schema to the last pixel of the UI.

🇮🇹 Sviluppatore full-stack in **Keix**: costruisco prodotti web data-driven, dal database all'interfaccia.

- 🔭 Currently working on the **Keix platform** — data quality, deduplication and analytics at scale
- ⚡ Focus: **TypeScript end-to-end**, monorepos, serverless and great DX
- 📍 Catania, Italy
